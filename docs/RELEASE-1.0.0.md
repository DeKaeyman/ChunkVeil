# ChunkVeil 1.0.0 — Stable release

ChunkVeil 1.0.0 is the first stable release. It strengthens underground confidentiality with fail-closed packet handling, particle and vibration-origin filtering, concealed light sanitization, fair entity scanning, improved diagnostics, and automatic additive config upgrades.

Tested with multiple players and continued server use on Paper 1.21.8, 1.21.11, 26.1.2, and 26.2. Install the ProtocolLib build listed for your server version and run `/chunkveil verify` after updating.

Existing explicit configuration values and custom worlds are preserved. Newly introduced default options are added automatically on startup.
