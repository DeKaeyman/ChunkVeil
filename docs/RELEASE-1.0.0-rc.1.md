# ChunkVeil 1.0.0-rc.1 — First 1.0 release candidate

This release candidate adds confidentiality-first packet failure handling, particle/vibration/light protection, improved diagnostics, fair entity scanning, additive config upgrades, and recommended/strict configuration guidance.

Tested with multiple players on Paper 1.21.8, 1.21.11, 26.1.2, and 26.2. Use the ProtocolLib build listed for your server version and run `/chunkveil verify` after installation.

This is a pre-release. Back up the previous jar and configuration before updating, and report unexpected packet or performance behaviour before the final 1.0.0 release.
